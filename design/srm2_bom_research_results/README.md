## SRM2 Research Result Staging

Drop each research-agent result into the matching numbered file.

Companion planning docs:
- `design/srm2_bom_research_prompts.md`
- `design/srm2_report_ingestion_plan.md`

For each result file, include at minimum:
1. system boundary
2. functional decomposition
3. architecture options + recommendation
4. BOM draft
5. manufacturing route draft
6. test/verification
7. failure modes/maintenance
8. assumptions/uncertainty
9. sources/confidence
10. summary table (`existing equivalent`, `new IDs`, `blockers`, `generation`)

After a file is populated, process it using `design/srm2_report_ingestion_plan.md`.
