# SRM2 Per-Result KB Integration Plans

This folder contains one planning file per report in `design/srm2_bom_research_results/`.

Each plan includes:
- report scope summary
- current KB mapping (reuse candidates)
- decision (`reuse` / `variant` / `new` / `defer`)
- proposed KB deltas (IDs/files to add or update)
- machine requirements for any new process
- key risks / unresolveds before implementation

Planning only: these files do not change KB YAML yet.
