# HV Grounding And Return Review

Status: boundary review completed for current Level-2 EBF3 grounding and return
model. Physical topology remains deferred.

Purpose:

  platform continuity, and low-voltage measurement paths.

  `ebf3_beam_current_return_strap`, or controls ADC items from becoming generic

## Boundary Model

Use four separate concepts:

1. **Protective grounding / bonding**: equipment chassis, tank enclosure, cabinet
   chassis, and service safety bonding. This is not the same as beam-current
   measurement return.
2. **HV source return / reference**: electrical return/reference node for the
   accelerating HV source. The regulated source belongs to power supplies; the
   exact physical return conductor and connection topology are not source-fixed.
3. **Beam-current return / substrate continuity**: conductive path from
   substrate/platform region for beam-current stability and possible current
   measurement. Platform-attached strap remains with four-axis positioning.
4. **Low-voltage sensing path**: isolated, scaled, or conditioned signals from
   HV/beam sensors into controls. Controls own acquisition and logic, not the
   HV-side primary conductor or sensor body.

## Source Evidence And Use

### RAW-BINP-60KEV-30KW

Evidence:

- "beam current, cathode heat current"
- "magnetic lens and correctors currents"
- "blocking state"
- "control and analogue grounds are isolated from external signals and grounds"

Use:

- Supports keeping beam-current and supply-current measurement visible to
  controls.
- Supports treating measurement ground isolation as a controls/interface concern.
- Does not define the physical EBF3 beam-current return conductor.

### RAW-BINP-60KV-15KW-HV-TANK

Evidence:

- "Output current"
- "Breakdown protection controls output current"
- "input current of transformer"
- "control and analogue grounds are isolated from external signals and grounds"

Use:

- Supports HV output/current monitoring and protection.
- Supports keeping HV-side current sensing near the HV source/tank boundary.
- Does not make tank protective ground the same thing as beam-current return.

### RAW-NASA-EBF-PATENT

Evidence:

- "means for providing electrical continuity"
- "grounding element"
- "current generated by the electron beam"
- "current sensor"
- "voltage sensor"

Use:

- Supports a positioning/platform continuity function near the substrate.
- Supports current and voltage sensing as real machine functions.
- Does not define exact grounding strap geometry or cabinet return routing.

### LOCAL-EBF3-FOUR-AXIS-POSITIONING-TABLE

Evidence:

- FS-24 candidate: beam-current return strap.

Use:

- Introduces the platform/substrate return-strap candidate.
- Candidate-only; it does not prove the full system return topology.

### LOCAL-EBF3-HV-TANK-TABLE

Evidence:

- HV-12 candidate: output or return current monitor.
- HV-15 candidate: tank grounding, shielding, and service interlock hardware.

Use:

- Introduces HV-side monitor and tank grounding candidates.
- Candidate-only; it does not assign global return ownership.

### LOCAL-EBF3-CONTROLS-MAPPING

Evidence:

- CTL-5 ADC handles voltage/current/temperature feedback.
- CTL-6 handles isolated signal conditioning.
- CTL-12 handles safety, alarm, and blocking logic.

Use:

- Supports assigning low-voltage acquisition, isolation, logging, and decisions
  to controls.
- Does not move primary HV sensors or platform straps into controls.

### LOCAL-EBF3-POWER-SUPPLIES-MAPPING

Evidence:

- Accelerating-HV output and power-supply control-board concepts are retained as
  deferred/derived candidates after the power-supplies Level-2 audit.

Use:

- Supports power supplies owning regulated HV source/reference electronics.
- Does not justify modeling a specific external return conductor yet.

### WEB-SPELLMAN-SL2KW-MANUAL

Evidence:

- "High voltage power supplies must always be grounded"
- "load and power supply is discharged"

Use:

- Supports protective grounding and discharge as safety requirements.
- Does not define EBF3 return-path physical ownership.

## Decision Matrix

| Function/candidate | Decision | Owning item/subsystem | Rationale |
| --- | --- | --- | --- |
| HV tank protective grounding terminal | Keep leaf | `ebf3_hv_tank_grounding_terminal` / HV tank | Physical bonding point on tank enclosure belongs to the tank package. |
| HV tank shielding/bonding straps beyond terminal | Defer | HV tank / cabin / power supplies | Source supports grounding need, not exact shield or strap layout. |
| Accelerating HV regulated source and reference electronics | Defer as power-supply/HV-source function | `ebf3_accelerating_voltage_dc_supply` | Power supplies own regulated source/reference functions, but this is not a source-table Level-2 row after the power-supplies audit. |
| External HV return conductor or cabinet return bus | Defer / split boundary | power supplies / HV tank / positioning / gun | Real function, but no source fixes whether it is cable, cabinet bus, chamber bond, platform strap, or combined topology. |
| Platform/substrate beam-current continuity strap | Keep in positioning | `ebf3_beam_current_return_strap` | NASA source supports platform continuity; current item is attached to the moving substrate/platform region. |
| Beam-current measurement primary sensor | Keep current HV leaf, type unresolved | `ebf3_hv_output_return_current_monitor` | HV-side monitor remains visible, but shunt/CT/Hall/return-leg placement is unresolved. |
| Beam diagnostic collector signal return/shield | Defer / split boundary | fixed gun / controls | Gun owns pickup hardware and local wiring; controls owns DAQ and conditioning. Shield termination policy is not source-fixed. |
| Voltage divider high-voltage chain | Keep in HV tank | `ebf3_hv_output_voltage_divider_sensing` | HV-side scaled voltage hardware belongs near HV tank/output. |
| Low-voltage ADC/signal conditioning | Keep in controls | `ebf3_analog_input_adc_module`, `ebf3_sensor_interface_module` | Controls own acquisition and isolated signal conditioning. |
| Blocking/interlock decision logic | Keep in controls | `ebf3_safety_blocking_logic` | Controls own decision logic; physical switches remain with their hardware package if sourced. |
| PSU internal measurement/control board | Defer as power-supply child detail | `ebf3_power_supply_control_board` | Internal PSU controller is not central controls, but it is not a source-table Level-2 row. |

## Manufacturing Readiness

No grounding/return item becomes local-ready from this review. Required missing
work includes conductor sizing, insulation/creepage, chassis bonding topology,
ground-fault behavior, beam-current measurement topology, signal isolation,
vacuum/feedthrough routing, service discharge procedure, and safety validation.
